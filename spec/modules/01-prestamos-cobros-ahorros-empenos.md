# #01 — Software de Préstamos + Cobros + Ahorros + Empeños

> Aplica sobre `00-MASTER.md`. Slug: `prestamos` (+ `prestamos-cobros`).

```text
Construye un sistema financiero integral para administrar préstamos, cobros, ahorros y empeños.

MÓDULOS:
- Clientes
- Préstamos
- Cuotas
- Cobranza
- Pagos
- Ahorros
- Movimientos
- Empeños
- Garantías
- Tasaciones
- Caja
- Reportes
- Morosidad
- Comisiones
- Intereses
- Usuarios
- Auditoría

PRÉSTAMOS:
- Crear solicitud.
- Evaluación.
- Aprobación/rechazo.
- Monto.
- Tasa.
- Plazo.
- Frecuencia de pago.
- Tabla de amortización.
- Cuotas.
- Mora.

- Refinanciación.
- Reestructuración.
- Estado del préstamo.

AHORROS:

- Retiros.

- Saldos.
- Historial.

EMPEÑOS:

- Estado.
- Renovación.
- Recuperación.

IA:
- Score de riesgo.
- Predicción de morosidad.
- Priorización de cobranza.
- Detección de operaciones anómalas.
- Recomendación de condiciones.

Crear dashboards separados para administrador y cliente.
```
